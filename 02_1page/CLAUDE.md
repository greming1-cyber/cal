# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## 프로젝트 목적

20년차 개발자인 사용자를 소개하는 **원페이지 개인 홈페이지**. 포트폴리오와 개발 역량을 알리는 것이 목표다. 섹션 구성, 기능, 완료 기준은 `PRD.md`를 따른다.

- **데이터베이스를 연결하지 않는다.** 서버/백엔드/DB 없이 정적 파일만으로 동작해야 한다. 프로필·경력·프로젝트 같은 콘텐츠는 HTML 안이나 정적 데이터(JS/JSON 파일)로 관리한다.
- 문의 폼처럼 서버가 필요해 보이는 기능은 `mailto:` 링크나 외부 링크로 대체한다.

## 저장소 구조와 관례

- git 저장소 루트는 이 폴더가 아니라 상위 폴더 `D:\ChaAI`다. 이 폴더(`02_1page`)는 그 안의 하위 프로젝트 중 하나다.
- 기존 프로젝트(상위 폴더의 `계산기_*.html`)는 **빌드 도구 없이 단일 HTML 파일**로 작성되어 있고, 기획서/사용법은 한국어 Markdown 문서로 함께 둔다. 별도 요청이 없으면 같은 방식(정적 HTML/CSS/JS, 빌드 단계 없음)을 따른다.
- 개발 중 확인은 HTML 파일을 브라우저에서 직접 열거나, 로컬 서버를 띄워 http://127.0.0.1:8000 에서 확인한다: `python -m http.server 8000 --bind 127.0.0.1` (이 폴더에서 실행). 패키지 매니저·테스트·린트 설정은 현재 없다.
- 페이지는 `index.html` 한 파일이다. 이름·경력·프로젝트 등 모든 콘텐츠는 `<script>` 안의 `DATA` 객체에 모여 있고, `render()`가 이를 각 섹션에 그린다. 내용 수정은 `DATA`만 고치면 된다.

## 배포 및 커밋

- 배포는 Vercel 정적 호스팅이며, 설정은 저장소 루트의 `../vercel.json`에 있다. 현재 루트 경로(`/`)가 `/계산기_코덱스.html`로 rewrite 되어 있으므로, 이 홈페이지를 사이트 루트로 노출하려면 `vercel.json`의 rewrite를 수정해야 한다 (기존 계산기 경로를 깨지 않도록 주의).
- 저장소는 `core.hooksPath=.githooks`로 설정되어 있고, `.githooks/post-commit` 훅이 **커밋할 때마다 자동으로 `git push`** 한다. 즉 커밋 = 원격 공개이므로, 커밋 전에 내용을 확인한다.
