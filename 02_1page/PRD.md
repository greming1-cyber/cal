# 개발자 원페이지 홈페이지 PRD

## 1. 개요

20년차 개발자인 나를 소개하는 원페이지 홈페이지를 만든다. 방문자(채용 담당자, 프로젝트 의뢰인, 동료 개발자)가 한 화면을 스크롤하면서 경력, 기술 역량, 대표 프로젝트를 빠르게 파악하고 바로 연락할 수 있게 한다.

## 2. 목표와 비목표

**목표**

- 30초 안에 "누구인지, 무엇을 잘하는지, 어떻게 연락하는지"가 전달된다.
- 20년 경력의 깊이를 보여주되, 핵심 위주로 간결하게 보여준다.
- 데스크톱과 모바일 모두에서 보기 좋게 표시된다.

**비목표**

- 데이터베이스, 백엔드 서버, 로그인, 관리자 페이지는 만들지 않는다.
- 블로그, 게시판, 댓글처럼 데이터를 저장하는 기능은 만들지 않는다.
- 다국어 지원은 첫 버전 범위에서 제외한다.

## 3. 대상 사용자

| 사용자 | 알고 싶은 것 | 원하는 행동 |
| --- | --- | --- |
| 채용 담당자 | 경력 요약, 주요 기술, 리더십 경험 | 이력서 확인, 연락 |
| 프로젝트 의뢰인 | 해결해 본 문제, 결과물 | 프로젝트 상세 확인, 문의 |
| 동료 개발자 | 기술 스택, 오픈소스 활동 | GitHub 방문 |

## 4. 화면 구성 (위에서 아래 순서)

| 섹션 | 내용 |
| --- | --- |
| 상단 내비게이션 | 이름/로고, 섹션 이동 메뉴. 스크롤해도 상단에 고정 |
| 히어로 | 이름, 한 줄 소개(예: "20년차 풀스택 개발자"), 짧은 소개 문구, 연락하기·이력서 버튼 |
| 소개 (About) | 개발 철학과 강점을 3~5문장으로. 경력 연수, 프로젝트 수 등 핵심 숫자 강조 |
| 기술 역량 (Skills) | 언어, 프레임워크, 인프라/DevOps, 데이터 등 분야별로 묶어 표시 |
| 경력 (Experience) | 회사·기간·역할·주요 성과를 타임라인으로 표시. 최근 경력부터 |
| 포트폴리오 (Projects) | 대표 프로젝트 카드: 이름, 기간, 역할, 사용 기술, 성과, 링크. 기술별 필터 제공 |
| 연락처 (Contact) | 이메일(`mailto:`), GitHub, LinkedIn 등 외부 링크 |
| 푸터 | 저작권 표시, 마지막 업데이트 날짜 |

## 5. 필수 기능

- 메뉴를 누르면 해당 섹션으로 부드럽게 스크롤한다.
- 스크롤 위치에 따라 현재 섹션 메뉴를 강조한다.
- 포트폴리오를 기술 태그로 필터링한다(예: Java, React, AWS). 서버 없이 브라우저 안에서 처리한다.
- 프로젝트 카드를 누르면 상세 내용을 모달 또는 펼침 영역으로 보여준다.
- 다크 모드와 라이트 모드를 전환하고, 선택한 값은 브라우저(localStorage)에 저장한다.
- 이메일 주소 복사 버튼을 제공한다.
- 모바일에서는 메뉴를 햄버거 버튼으로 접는다.

## 6. 콘텐츠 관리

- 데이터베이스 없이, 프로필·기술·경력·프로젝트 정보를 정적 데이터로 관리한다.
- 콘텐츠는 HTML 안의 데이터 영역(JS 객체) 한 곳에 모아 두고, 내용을 바꿀 때 그 부분만 수정하면 되도록 한다.
- 이미지(프로필 사진, 프로젝트 스크린샷)는 같은 폴더의 정적 파일로 둔다. 이미지가 없어도 화면이 깨지지 않게 한다.

## 7. 기술 요구사항

- 빌드 도구 없이 정적 HTML/CSS/JavaScript로 만든다. 기존 계산기 프로젝트와 같은 방식이다.
- HTML 파일을 브라우저로 바로 열어도 동작한다.
- Vercel 정적 호스팅으로 배포한다. 저장소 루트의 `vercel.json` 설정을 수정하되, 기존 계산기 페이지 주소는 그대로 유지한다.
- 검색과 공유를 위해 `title`, `description`, Open Graph 메타 태그를 넣는다.
- 시맨틱 태그, 이미지 대체 텍스트, 키보드 탐색 등 기본 접근성을 지킨다.

## 8. 완료 기준

1. 히어로 영역에서 이름, 한 줄 소개, 연락 버튼이 첫 화면에 보인다.
2. 메뉴를 누르면 해당 섹션으로 이동하고, 스크롤하면 현재 메뉴가 강조된다.
3. 기술 태그를 고르면 해당 기술을 쓴 프로젝트만 보인다.
4. 다크 모드를 켜고 새로고침해도 다크 모드가 유지된다.
5. 휴대폰 화면(폭 360px)에서 글자와 카드가 겹치거나 잘리지 않는다.
6. 인터넷 없이 HTML 파일을 열어도 레이아웃이 깨지지 않는다(외부 폰트는 없을 때 기본 폰트로 표시).
7. 배포 주소에서 홈페이지가 열리고, 기존 계산기 페이지도 계속 열린다.
8. 데이터베이스나 서버 호출 없이 모든 기능이 동작한다.

## 9. 준비할 콘텐츠 (사용자 입력 필요)

- 이름, 한 줄 소개, 프로필 사진
- 주요 기술 스택과 숙련도
- 경력 목록(회사, 기간, 역할, 성과)
- 대표 프로젝트 3~6개(설명, 사용 기술, 성과, 링크, 스크린샷)
- 연락처(이메일, GitHub, LinkedIn 등)와 이력서 PDF 여부

## 10. 향후 확장

방문자 통계(외부 분석 도구), 영문 버전, 기술 블로그 링크 연동은 이후 확장 기능으로 둔다.

이 문서는 목표 기능을 정리한 기획서이며, 각 기능의 현재 구현 완료 여부를 의미하지 않는다.
